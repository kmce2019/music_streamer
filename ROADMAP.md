# Roadmap

## Phase A: Foundation
- Flutter scaffold + routing + DI + theme + l10n setup.
- Core models and strict layering conventions.

## Phase B: Library + Playback
- Local folder import, library browsing, favorites, history.
- Queue playback controls with mini/full player.

## Phase C: Plugin Framework
- Manifest lifecycle, capability declarations, plugin policy checks.
- Safe internet-radio example plugin.

## Phase D: Polish + Sync/Import-Export
- Better empty/error states, advanced settings.
- Import/export metadata with schema versioning.

## Phase E: Advanced Features
- Rust helpers (metadata, cache index, signatures).
- Optional approved-source plugins and richer recommendations.
